# MyVault

Minimal Android app for retrieving and storing an encrypted flag.

The app has a single button in `MainActivity`. Pressing it asks `FlagViewModel`
to generate an Android KeyStore RSA key pair, send the public key to the flag
server with its attestation certificate chain, decrypt the returned AES
session key with the private KeyStore key, decrypt the encrypted flag, and save
the plaintext flag to Preferences DataStore.

The handshake endpoint defaults to:

```text
https://vault.u18-2026.haruulzangi.mn/api/flag
```

Plaintext HTTP traffic is allowed only for debug builds. Release builds set
`android:usesCleartextTraffic="false"`.

Override it at build time with:

```sh
gradle assembleDebug -PflagEndpoint=https://example.test/handshake
```

Expected server request JSON:

```json
{
  "clientNonce": "base64 fresh 32-byte nonce",
  "publicKey": "base64 X.509 SubjectPublicKeyInfo RSA public key",
  "attestationCertificates": [
    "base64 DER Android key attestation leaf certificate",
    "base64 DER issuer certificate"
  ]
}
```

Expected server response JSON:

```json
{
  "encryptedSessionKey": "base64 RSA-OAEP encrypted AES key",
  "flagIv": "base64 AES-GCM IV",
  "encryptedFlag": "base64 AES-GCM ciphertext with tag",
  "aad": "base64 CBOR byte-string blob containing clientNonce"
}
```

`clientNonce` is a fresh 32-byte base64 value generated by the app for each
request. The app regenerates the Android KeyStore handshake key for each fetch
with `clientNonce` as the key attestation challenge. The server verifies the
attestation certificate chain, checks the leaf certificate public key matches
`publicKey`, and rejects the request if the attestation challenge does not match
`clientNonce`.

The server binds the encrypted response to the nonce by using it as AES-GCM AAD,
so a captured encrypted response cannot be replayed against a later request.

`aad` must be `base64(CBOR byte string(clientNonce))`. For the required
32-byte nonce, the raw AAD bytes are `0x58 0x20` followed by the 32 raw nonce
bytes.

The OpenAPI contract for the endpoint is in `docs/flag-api.openapi.yaml`.
